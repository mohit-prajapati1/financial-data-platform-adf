# Financial Data Platform ADF

This repository contains the Azure Data Factory (ADF) configuration and related files for the financial data platform.

## Directory Structure

- **adf/** - Azure Data Factory pipeline definitions and configurations
- **sql/** - SQL scripts and stored procedures
- **data/** - Sample data and data-related files
- **documentation/** - Project documentation
- **tests/** - Test files and test configurations
- **scripts/** - Utility and deployment scripts
